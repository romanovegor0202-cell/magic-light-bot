# Magic Light — Telegram Bot

Готовый Telegram-бот-каталог для студии спецэффектов Magic Light.

## Что умеет

- приветствие и главное меню;
- каталог по категориям;
- карточки товаров с фото, описанием и ценами;
- добавление товаров в корзину;
- изменение количества `+ / -` прямо в корзине;
- автоматический пересчёт стоимости;
- оформление заявки: имя, телефон, дата, место, комментарий;
- предварительный просмотр заявки;
- отправка заявки менеджеру в Telegram;
- кнопка прямой связи с менеджером;
- SQLite для хранения корзин и заявок;
- все настройки в `.env`.

CRM, онлайн-оплата и подбор спецэффектов намеренно не включены.

## 1. Установка

Рекомендуется Python 3.11+.

```bash
python -m venv .venv
```

Windows:
```bash
.venv\\Scripts\\activate
```

Linux/macOS:
```bash
source .venv/bin/activate
```

```bash
pip install -r requirements.txt
```

## 2. Настройка

Скопируйте `.env.example` в `.env` и заполните:

```env
BOT_TOKEN=сюда_токен_бота
MANAGER_ID=сюда_telegram_id_менеджера
MANAGER_USERNAME=username_менеджера_без_@
MANAGER_PHONE=+79999999999
COMPANY_NAME=Magic Light
```

`MANAGER_ID` — числовой Telegram ID. Бот должен иметь возможность написать этому пользователю. Для этого менеджер должен хотя бы один раз открыть/запустить бота.

## 3. Запуск

```bash
python bot.py
```

База `magic_light.db` создастся автоматически.

## Структура

- `bot.py` — точка входа;
- `config.py` — настройки;
- `database.py` — SQLite;
- `catalog_data/products.json` — каталог и цены;
- `handlers/` — логика бота;
- `keyboards/` — кнопки;
- `media/` — изображения из предоставленного каталога.

## Важно по ценам

- Тяжёлый дым: первый запуск 10 000 ₽, каждый дополнительный 6 000 ₽.
- Ночные салюты: в каталоге указана цена от 5 000 до 30 000 ₽, поэтому в корзине показывается диапазон и пометка, что окончательная стоимость согласовывается менеджером.
- Конфетти-пушка: 4 000–6 000 ₽ в зависимости от объёма.

Изменить товар или цену можно непосредственно в `catalog_data/products.json`, перезапустив бота.
